🎯 **What:** The testing gap addressed
The `scripts/check-relative-paths.mjs` script verifies that built assets under `dist/` use relative paths to ensure correct proxying. Previously, this important build verification step had no test coverage.

📊 **Coverage:** What scenarios are now tested
This PR introduces full integration test coverage using Playwright's Node.js test runner in `tests/check-relative-paths.spec.ts`. It leverages temporary directories via `node:fs` `mkdtempSync` to ensure isolated test runs without mutating the real repository. Scenarios covered:
- Exits with status 2 if the `dist/` directory is missing.
- Exits with status 0 if all parsed paths are correctly relative.
- Exits with status 1 if invalid absolute paths (like `href="/style.css"`) are encountered.
- Correctly recursively walks and verifies nested directories within `dist/`.

✨ **Result:** The improvement in test coverage
The deployment safety script now has deterministic and isolated regression tests, providing confidence that invalid static assets will be reliably caught before portal deployment.
